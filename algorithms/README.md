# Algorithms

This directory contains course materials for Algorithms.

## Structure

- `assignments/` - Course assignments
- `data/` - Datasets and input files
- `lectures/` - Lecture materials and examples
- `notes/` - Course notes and summaries
- `projects/` - Course projects
- `venv/` - Python virtual environment

## Setup

To set up the virtual environment:

```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

## Usage

Activate the virtual environment before working on course materials:

```bash
source venv/bin/activate
```
